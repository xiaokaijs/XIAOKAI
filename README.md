# 施凯峰个人作品集网站

React + Vite 个人作品集，内容来自现有简历和作品素材。页面定位为 UE5 与 Unity 方向持续深耕的游戏开发 / 技术美术实践，加入冷色 Grainient 动态底层、完整首屏 Opening、章节标题遮罩进场、项目媒体 reveal 与轻量滚动视差。

## 本地运行

```powershell
pnpm install
pnpm dev
```

开发服务器默认在 `http://127.0.0.1:5173/XIAOKAI/` 启动。

- `01 PROFILE`：MMD03 风格化角色中段循环预览
- `UE5.8 风格化角色渲染`：风格化渲染技术拆解，点击后播放
- `AI 辅助《博德之门 3》逆向渲染`：完整 38 秒 UE5.8 场景重建演示，进入视口后循环播放
- `Unity 原神风格化渲染`：完整 10 秒芙宁娜光照演示，进入视口后循环播放
- `UE PCG Forest`：PCG Forest 自动循环预览
- `Escape`：PC 原作精选流程自动循环预览
- `Escape VR 扩展`：VR 扩展自动循环预览
- `Unity AR 桌宠原型`：Unity 2022 移动端 AR 真机片段
- `零点回声：黑匣协议`：Three.js 三章流程精选片段
- `涌现：第一粒光`：已正式提交 TapTap GameJam 的叙事解谜原型，保留完整约 1 分 45 秒演示与音轨，展示前期玩法，点击后才加载和播放

网页影片提供三个层级：`public/media/previews` 为桌面轻量版，`public/media/mobile` 为手机与慢网版，`public/media/films` 为保留的高清原片。桌面循环预览接近视口时仅加载元数据，进入视口后播放；手机、减少动态和节流模式先显示海报、点击后播放。技术拆解也在点击后才加载。页面最多同时播放一个视频，离屏暂停，远离视口 6 秒后释放网络请求与解码器；切换标签页暂停。加载慢与失败均有反馈及重试，字幕区可直接打开高清原片。

所有预览保留原时长和画面，使用兼容手机的 H.264 / yuv420p / faststart；自动循环预览静音，点击播放的技术拆解保留原 AAC 音轨，所有视频均保留原片入口。BG3 项目说明区分 AI 辅助、个人验证与原作资产；Unity 项目说明第三方角色与动作资产来源，不将其标为个人建模作品。

## 2026-10-27 访问与移动端优化

- 十段影片原片合计 78.56 MB；桌面预览合计 41.66 MB（减少约 47%），手机预览合计 19.78 MB（减少约 75%），含技术拆解原音轨。这是全部影片总量，不是首屏下载量；手机首屏不请求 MP4
- 十张海报从 1.27 MB 降至 WebP 合计 0.45 MB；匕首图片按屏幕选择 15 KB 小图或原图
- 手机恢复紧凑导航，调整标题、竖版媒体、触控按钮、安全区域与锚点偏移，移除高成本模糊滤镜
- 首屏海报优先加载；React 主页面、动画库与 WebGL 工具分开加载。HTML 初始占位与 React 错误回退保留 Bilibili 和简历入口
- 使用 GitHub Pages 项目路径 `/XIAOKAI/`。页面性能改善不能替代网络连通性；发送给他人时使用公开 HTTPS 地址，不能发送 `127.0.0.1` 本地预览

Opening 和各模块进入动画在单次页面浏览中只播放一次，刷新页面后重新播放；直接访问 `#work` 等锚点时会跳过首屏 Opening。
