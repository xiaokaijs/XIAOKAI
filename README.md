# 施凯峰个人作品集网站

React + Vite 个人作品集，内容来自现有简历和作品素材。页面定位为 UE5 与 Unity 方向持续深耕的游戏开发 / 技术美术实践，加入冷色 Grainient 动态底层、完整首屏 Opening、章节标题遮罩进场、项目媒体 reveal 与轻量滚动视差。

## 本地运行

```powershell
pnpm install
pnpm dev
```

开发服务器默认在 `http://127.0.0.1:5173/XIAOKAI/` 启动。

## 当前页面

- 全屏视频 Hero，使用《作品集.mp4》完整 1 分 55 秒内容的 720P 静音网页压缩版
- 首屏 Opening 使用分栏遮罩、标题压缩归位与分层错峰进场
- `GSAP + ScrollTrigger` 负责一次性章节进入动画；媒体视差随滚动持续变化
- `OGL` Grainient 使用冷白、青灰与深蓝灰配色，并在离屏、后台或减少动态模式下暂停或静态化
- `01 PROFILE` 下展示 MMD03 中段 15 秒动态循环
- 七个核心项目章节，新增 AI 辅助 BG3 逆向渲染与 Unity 原神风格化渲染；Escape PC 原作与 VR 扩展分开呈现；视频和图片均直接呈现在正文中
- `实验与拓展` 区域展示 Unity AR 桌宠与零点回声两个跨引擎项目
- 个人优势与工具链
- 整屏联系方式收尾页

## 影片索引

- `01 PROFILE`：MMD03 风格化角色中段循环预览
- `UE5.8 风格化角色渲染`：风格化渲染技术拆解，点击后播放
- `AI 辅助《博德之门 3》逆向渲染`：完整 38 秒 UE5.8 场景重建演示，进入视口后循环播放
- `Unity 原神风格化渲染`：完整 10 秒芙宁娜光照演示，进入视口后循环播放
- `UE PCG Forest`：PCG Forest 自动循环预览
- `Escape`：PC 原作精选流程自动循环预览
- `Escape VR 扩展`：VR 扩展自动循环预览
- `Unity AR 桌宠原型`：Unity 2022 移动端 AR 真机片段
- `零点回声：黑匣协议`：Three.js 三章流程精选片段

网页使用的 H.264 优化副本位于 `public/media/films`，海报位于 `public/media/posters`。循环预览在接近视口时才加载，离开视口后自动暂停；技术拆解使用 `preload="none"` 和原生控制条，仅在用户点击播放时请求媒体数据。原始高码率网页素材备份保留在 `tmp/original-media`。

新增两段影片保留完整时长，使用 1080P / 30 FPS、H.264、静音与 faststart 的网页副本，原视频保留在原始位置。BG3 项目说明区分 AI 辅助、个人验证与原作资产；Unity 项目说明第三方角色与动作资产来源，不将其标为个人建模作品。

Opening 和各模块进入动画在单次页面浏览中只播放一次，刷新页面后重新播放；直接访问 `#work` 等锚点时会跳过首屏 Opening。

后续可继续替换个人照片、补充作品详情页并部署正式域名。
