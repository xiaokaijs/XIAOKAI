# 施凯峰个人作品集网站

React + Vite 个人作品集，内容来自现有简历和作品素材。页面定位为 UE5 与 Unity 方向持续深耕的游戏开发 / 技术美术实践，加入冷色 Grainient 动态底层、完整首屏 Opening、章节标题遮罩进场、项目媒体 reveal 与轻量滚动视差。

## 本地运行

```powershell
pnpm install
pnpm dev
```

开发服务器默认在 `http://127.0.0.1:5173/XIAOKAI/` 启动。

- `UE PCG Forest`：PCG Forest 自动循环预览
- `Escape`：PC 原作精选流程自动循环预览
- `Escape VR 扩展`：VR 扩展自动循环预览
- `Unity AR 桌宠原型`：Unity 2022 移动端 AR 真机片段
- `零点回声：黑匣协议`：Three.js 三章流程精选片段
- `涌现：第一粒光`：已正式提交 TapTap GameJam 的叙事解谜原型，保留完整约 1 分 45 秒演示与音轨，展示前期玩法，点击后才加载和播放

网页影片提供三个层级：`public/media/films` 为从原始录屏制作的 1080P 高清版（AR 为原始 720×1280），`public/media/previews` 为 720P 流畅版（AR 为 540×960），`public/media/mobile` 为保留的省流版。正常桌面默认高清、普通手机默认流畅，只有慢网或节流模式默认省流；正文每段视频可独立选择“自动 / 高清 / 流畅 / 省流”。切换时保留播放进度与暂停状态，尚未开始的影片不因选画质而请求 MP4。高清版本也经过网页编码，并非未经压缩的原文件。

桌面循环预览接近视口时仅加载元数据，进入视口后播放；手机、减少动态和节流模式先显示海报、点击后播放。技术拆解也在点击后才加载。页面最多同时播放一个视频，离屏暂停，远离视口 6 秒后释放网络请求与解码器；切换标签页暂停。加载慢与失败均有反馈及重试，字幕区可直接打开高清版本。

所有版本保留既定剪辑范围，使用兼容手机的 H.264 / yuv420p / faststart；自动循环预览静音，点击播放的技术拆解与 GameJam 保留音轨。BG3 项目说明区分 AI 辅助、个人验证与原作资产；Unity 项目说明第三方角色与动作资产来源，不将其标为个人建模作品。
